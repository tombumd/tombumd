tombumd (同步马) Privacy Policy · 隐私政策

Effective date · 生效日期：2026-10-04
Applies to · 适用于：the tombumd (同步马) browser extension (version 6.0.0 and later) and the single-file offline edition · tombumd（同步马）浏览器插件（6.0.0 及以后版本）与单文件离线版

English

Summary: tombumd does not collect, transmit, sell or share any personal data. Everything you write stays on your device.

1. What the extension does

tombumd is an offline Markdown editor. Clicking its toolbar button opens the editor in a browser tab. The editor, all of its code and all of its libraries are packaged inside the extension; nothing is downloaded from the internet.

2. Data we collect

None. The extension has no server, no account system, no analytics, no telemetry, no crash reporting, no advertising and no third-party SDKs. The developer never receives your documents, settings or any information about you or your device.

3. Data stored on your device

To work as an editor, the extension stores the following only locally, in your browser's storage for this extension (IndexedDB / localStorage):

  • the documents you create or import, their version history and the recycle bin;
  • your settings (layout, export styles, etc.);
  • a local activity log (used only to show you the history of edits/sync events; it never leaves your device);
  • a cache of rendered formulas, so documents open faster.

If you choose "Link a local folder" (available in browsers that support the File System Access API), the extension reads and writes Markdown files and images only inside the folder you pick, and only after the browser asks for your permission. You can unlink the folder at any time.

You can delete this data at any time by deleting documents in the editor, by clearing the extension's site data, or by uninstalling the extension (uninstalling removes all of it).

4. Network access

The extension itself makes no network requests. The only exceptions are caused by content you put into your document:

  • If your Markdown references an image by an http(s):// address, the browser loads that image from that website to display it, just like any web page would. When you export to Word/LaTeX or copy to Word/WeChat, the editor may download such images so it can embed them in the output.
  • Links in your document are opened only when you click them.

Those websites receive the normal information any web request carries (such as your IP address) and are governed by their own privacy policies. If you don't want this, use local images only.

5. Clipboard and files

The editor writes to the clipboard only when you use a Copy command, and reads clipboard content only when you paste. Exported files (Markdown, HTML, Word, PDF, PNG, LaTeX) are saved through your browser's normal download mechanism to a location you control.

6. Permissions

The extension requests no browser permissions. It cannot read or change the web pages you visit, your browsing history, tabs, cookies or bookmarks.

7. Children

The extension does not collect any data from anyone, including children.

8. Changes

If this policy changes, the new version will be published at the same address with a new effective date. Any change that would introduce data collection would be announced in the extension's store listing and would require your explicit consent first.

9. Contact

Questions: open an issue at https://github.com/tombumd/tombumd/issues (please don't post private content in public issues).

中文

一句话：同步马不收集、不上传、不出售、不分享任何个人数据。你写的所有内容都只留在你自己的设备上。

1. 插件做什么

同步马是一个离线 Markdown 编辑器。点工具栏按钮，会在浏览器标签页中打开编辑器。编辑器本身、全部代码和第三方库都打包在插件里，不会从网络下载任何东西。

2. 我们收集的数据

没有。 插件没有服务器、没有账号系统、没有统计分析、没有遥测、没有崩溃上报、没有广告，也没有任何第三方 SDK。开发者永远收不到你的文档、设置，或任何关于你和你设备的信息。

3. 保存在你设备上的数据

为了正常编辑，插件会把以下内容只保存在本机浏览器为本插件分配的存储空间里（IndexedDB / localStorage）：

  • 你新建或导入的文档、版本历史和回收站；
  • 你的设置（布局、导出样式等）；
  • 本地操作日志（只用于给你查看编辑/同步记录，从不离开你的设备）；
  • 公式渲染缓存，用于加快打开速度。

如果你使用「定位本地文件夹」（浏览器支持 File System Access API 时可用），插件只会读写你选定的那个文件夹里的 Markdown 文件和图片，并且必须先经过浏览器弹窗授权。你可以随时撤销定位。

你可以随时删除这些数据：在编辑器里删除文档、清除本插件的网站数据，或直接卸载插件（卸载会全部删除）。

4. 网络访问

插件本身不发出任何网络请求。唯一的例外来自你自己写进文档的内容：

  • 如果你的 Markdown 用 http(s):// 地址引用了网络图片，浏览器会像打开普通网页一样，从那个网站加载图片来显示；在导出 Word / LaTeX 或复制到 Word / 公众号时，编辑器可能会下载这些图片，以便嵌入到输出文件中。
  • 文档里的链接只有在你点击时才会打开。

这些网站会收到普通网络请求都会带的信息（例如 IP 地址），并受它们各自的隐私政策约束。如果不希望这样，请只使用本地图片。

5. 剪贴板与文件

只有在你使用「复制」功能时，编辑器才写入剪贴板；只有在你粘贴时，才读取粘贴的内容。导出的文件（Markdown、HTML、Word、PDF、PNG、LaTeX）通过浏览器正常的下载功能，保存到你自己决定的位置。

6. 权限

插件不申请任何浏览器权限。它无法读取或修改你访问的网页，也无法访问你的浏览历史、标签页、Cookie 或书签。

7. 儿童

插件不收集任何人的数据，包括儿童。

8. 变更

本政策如有变化，新版本会发布在同一地址并更新生效日期。任何引入数据收集的改动，都会先在商店页面说明，并且必须事先征得你的明确同意。

9. 联系方式

有问题请在 https://github.com/tombumd/tombumd/issues 提 issue（请不要在公开 issue 中贴私人内容）。
